# Reglas permanentes del proyecto

1. Construir la landing sección por sección.
2. No avanzar a otra sección sin aprobación.
3. Mantener la identidad visual de Orán Soluciones.
4. Priorizar diseño responsive desde el comienzo.
5. Verificar escritorio, tablet y celular.
6. Utilizar componentes claros y reutilizables.
7. Evitar dependencias innecesarias.
8. Mantener buena accesibilidad y rendimiento.
9. Ejecutar el build después de cada cambio importante.
10. No reemplazar archivos de marca sin autorización.
